## 1. คำนิยามของ 5% ที่เหลืออยู่ (The Remaining 5% to Pilot Launch)

เพื่อให้คณะกรรมการและบอร์ดบริหารเข้าใจตรงกันอย่างโปร่งใส สถานะระบบในปัจจุบันคือ:
- **Code + Test Architecture = 100% สมบูรณ์** (145/145 Automated Tests ผ่านครบ)
- **Pilot Readiness = 95%** โดย **5% ที่เหลือเป็นขั้นตอนปฏิบัติการภาคสนามของมนุษย์ (Operational Fieldwork)** ซึ่งประกอบด้วย:

```
[แผนผัง 5% สุดท้ายก่อนเริ่มเคสคนไข้จริง]
┌────────────────────────────────────────────────────────────────────────┐
│ 1. การลงนามทางกายภาพ (Physical Signatures on Calibration Report)       │
│    - Medical Director + Chief Library Curator ลงนามและสแกนแนบ          │
├────────────────────────────────────────────────────────────────────────┤
│ 2. การเปิด Public HTTPS Tunnel สำหรับ LINE OA                          │
│    - เชื่อมต่อ Cloudflare Tunnel / ngrok เพื่อทดสอบ Webhook กับ LINE สด│
├────────────────────────────────────────────────────────────────────────┤
│ 3. การทดสอบในกลุ่มแพทย์ 2-3 ท่าน (Physician Dry-Run Workshop)          │
│    - ซ้อมเปิดกล่อง, ตรวจ SOAP, ตรวจ 39 แกน, และประเมินความพึงพอใจ     │
├────────────────────────────────────────────────────────────────────────┤

│    - วัดผลตามเกณฑ์ Success Criteria ก่อนรับเคสคนไข้จริง                │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. เกณฑ์ชี้วัดความสำเร็จของคลินิกนำร่อง (Pilot Success Criteria)

การประเมินเพื่ออนุมัติใช้งานจริง (Full Production Go-Live) จะต้องผ่านเกณฑ์ทั้ง 4 ข้อดังต่อไปนี้:

| ตัวชี้วัด (Key Metric) | เกณฑ์ขั้นต่ำ (Target Threshold) | วิธีการวัดผล (Measurement Method) | ความสำคัญ |
|---|:---:|---|---|
| **1. ความพึงพอใจของแพทย์ผู้ตรวจ (Physician Satisfaction)** | **$\ge 80.0\%$** | ค่าเฉลี่ยคะแนนจากแบบสอบถามแพทย์ 10 ข้อ (Likert Scale 1-5) | การยอมรับในการใช้งานจริงในเวชปฏิบัติ |
| **2. อัตราการสกัดกั้นข้อมูลหลอน (Guardrail Block Rate)** | **$100.0\%$** | คำกล่าวอ้างที่ไม่มีในตำราต้องถูก Redact / Reject 100% | ความปลอดภัยในชีวิตของผู้ป่วย (Patient Safety) |
| **3. อัตราการรั่วไหลของข้อมูลระบุตัวตน (PII Leak Rate)** | **$0.0\%$** | การสุ่มตรวจ AuditLog และ Outbound Payload ทุกเคสต้องไม่พบ PII | การปฏิบัติตามกฎหมาย PDPA มาตรา 26 |
| **4. เวลาเฉลี่ยในการตัดสินใจรักษา (Time-to-Decision)** | **$< 5$ นาที/เคส** | บันทึกเวลาตั้งแต่แพทย์ปลดล็อกกล่องจนถึงลงนามบันทึกคำสั่งการรักษา | ประสิทธิภาพและความคล่องตัวในคลินิก |

## 3. ขั้นตอนการตั้งค่า LINE OA สดเมื่อพร้อมออนไลน์ (Live Webhook Setup Guide)

เมื่อพร้อมเชื่อมต่อกับ LINE Official Account ในระบบจริง ให้ดำเนินการตามขั้นตอนดังนี้:

### ขั้นตอนที่ 1: เปิด HTTPS Tunnel
```bash
# ทางเลือกที่ 1: Cloudflare Tunnel (แนะนำสำหรับ Institutional Production)
cloudflared tunnel --url http://localhost:8000

# ทางเลือกที่ 2: ngrok (สำหรับการทดสอบเบื้องต้น)
ngrok http 8000
```

### ขั้นตอนที่ 2: อัปเดตการตั้งค่าใน `.env`
```ini
LINE_CHANNEL_SECRET=your_actual_channel_secret_here
LINE_CHANNEL_ACCESS_TOKEN=your_actual_access_token_here
```

### ขั้นตอนที่ 3: ตั้งค่า Webhook URL ใน LINE Developers Console
- **Webhook URL:** `https://<your-subdomain>.trycloudflare.com/patient/webhook/`
- **Use Webhook:** เปิด (Enabled)
- **Auto-reply messages:** ปิด (Disabled) เพื่อให้ระบบของ TSPI ตอบสนองเอง
