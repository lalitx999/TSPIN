# UI ใหม่ (พฤศจิกายน 2026)

แกะจากเว็บต้นแบบ 2 เว็บ เมื่อ 2026-11-09 โดยวัดค่าจริงจาก computed style (Meditex) และเก็บสีจาก pixel ของภาพหน้าจอ (Medicare เป็น Flutter วาดลง canvas จึงไม่มี CSS ให้อ่าน)

เราไม่ได้คัดลอกโค้ด รูป หรือไอคอนของต้นแบบ: ทั้งสองเป็นเทมเพลตที่ขายแบบมีลิขสิทธิ์ เราเอาแค่ระบบดีไซน์ (สี ระยะ ขนาด โครงหน้า) มาเขียนใหม่บน Bootstrap 5 ที่ใช้อยู่ ฟอนต์ใช้ Sarabun ตัวเดิมที่อยู่ในเครื่อง เพราะ Nunito Sans และ Inter ไม่มีตัวอักษรไทย

| ส่วน | ต้นแบบ | ไฟล์ของเรา |
|---|---|---|
| หน้าเว็บสาธารณะ | Meditex (st.ourhtmldemo.com/template/meditex-final) | `static/css/site.css`, `templates/layouts/public_base.html`, `templates/core/home.html` |
| ระบบภายใน (แพทย์/เจ้าหน้าที่) | Medicare web admin (getappui.com/medicare/web) | `static/css/admin.css`, `templates/layouts/doctor_base.html`, `templates/layouts/_doctor_nav.html`, `templates/patients/dashboard.html` |

### โครงหน้า (บนลงล่าง)

1. **แถบบนสุด** สูง 44px: ที่อยู่ซ้าย ไอคอนโซเชียลขวา เส้นล่าง `#EAEAEA` → ของเรา: เวลาทำการ, LINE, ฉุกเฉิน 1669
2. **Header** สูง ~84px พื้นขาว: โลโก้ไอคอนวงกลมเขียว + ชื่อตัวหนา, เมนูกลางตัวหนา 14px สีเข้ม (หน้าปัจจุบันเป็นสีเขียว), ไอคอนค้นหาขวา; เลื่อนลงแล้วติดบนพร้อมเงาบาง
3. **Hero** สูง 750px: ภาพเต็มกว้าง ด้านซ้ายจางเป็นขาว, หัวข้อ 2 บรรทัด บรรทัดแรกสีเข้มน้ำหนักปกติ บรรทัดสองสีเขียวตัวหนา, ปุ่มเขียว + ปุ่มดำ
4. **การ์ดนัดหมายลอย** ทับขอบล่าง hero (margin-top −120px): ขอบบนเขียว 3px, padding 50px 40px, 3 คอลัมน์ ฉุกเฉิน / เวลาทำการ (เส้นจุดนำสายตา) / ฟอร์มนัด
5. **แผนก** พื้น `#F4F4F4`: หัวข้อ “OUR **DEPARTMENTS**” (คำแรกบาง คำหลังเขียวหนา) + ลิงก์ “ดูทั้งหมด” ขวา, แผงขาวแบ่ง 4×2 ช่องด้วยเส้นบาง, ไอคอนเส้นเขียว 40px, ชื่อ 22px ตัวหนา, คำอธิบายเทา 3 บรรทัด
6. **Welcome** แบ่งครึ่ง: ข้อความ + โลโก้รางวัล + ปุ่ม ซ้าย, ภาพขวาชิดขอบ
7. **แถบชวนนัด** พื้นเขียวเต็ม สูง 210px: หัวข้อขาว 2 น้ำหนัก + ปุ่มขาวขวา
8. **รีวิวคนไข้** การ์ด 2 ใบ ขอบบนเขียว 3px ขอบรอบเทาอ่อน + ปุ่มเลื่อนสี่เหลี่ยมเทา
9. **แพทย์** การ์ด 3 ใบ: รูปบน พื้นเทา, ชื่อหนา, สาขาเทา, เส้นคั่น, คำอธิบาย
10. **บทความ + FAQ** สองคอลัมน์: รายการบทความรูปเล็กซ้าย; accordion ขวา ข้อที่เปิดมีขอบบนเขียว 3px และสัญลักษณ์ − / +
11. **แถบติดต่อ** พื้น `#F4F4F4`: 4 ช่อง ไอคอนเส้นเขียว + 2 บรรทัด
12. **Footer** พื้นขาว 4 คอลัมน์: เกี่ยวกับ / แผนก / ลิงก์ / จดหมายข่าว หัวข้อตัวหนา 16px
13. **แถบล่าง** ลิขสิทธิ์ซ้าย ลิงก์นโยบายขวา, ปุ่มกลับขึ้นบนสี่เหลี่ยมเขียวมุมขวาล่าง

## 2. Medicare: ระบบภายใน

### ค่าที่วัดได้ (จาก pixel)

| Token | ค่าในต้นแบบ | ใช้ในเรา |
|---|---|---|
| สีหลัก | `#D19C72` (ส้มอิฐอ่อน) | `--adm-accent: #C98B5B` เข้มขึ้นให้ตัวหนังสือบนปุ่มอ่านได้ |
| พื้นเมนูที่เลือก | `#F2E0D2` | `--adm-accent-soft: #F6E7DB` |
| หัวตาราง | `#FBF1E9` ตัวหนังสือสีหลัก | `--adm-accent-wash: #FBF3EC` |
| พื้นหลังหน้า | `#F3F3F3` | `--adm-canvas: #F3F3F3` |
| การ์ด / เมนูข้าง / แถบบน | `#FFFFFF` ไม่มีเส้นขอบ มุมโค้ง ~12px | เดียวกัน |
| เส้น | `#E8E9EB` | `--adm-line: #E8E9EB` |
| ฟอนต์ | sans-serif แบบ Inter: เมนู 14px, หัวหน้า 18px, ตาราง 13px | Sarabun 15–16px |
| ช่องกรอก | สูง 44px, เส้น 1px เทา มุมโค้ง 10px, ไอคอนนำหน้า | เดียวกัน |
| ปุ่ม | สีหลัก ตัวขาว เล็ก มุมโค้ง 6px; ปุ่มรองเทาอ่อน | เดียวกัน |
| โหมดมืด | พื้น `#1E1E1E` การ์ด `#2A2A2A` สีหลักเดิม | มีปุ่มสลับที่แถบบน จำค่าในเบราว์เซอร์ |

### โครงหน้า

- **เมนูข้าง** การ์ดขาวลอย ห่างขอบ 16px กว้าง ~270px สูงเต็มจอ: โลโก้ตัวหนาสีหลักตรงกลาง, หัวกลุ่มตัวเล็กเทา, รายการ = ไอคอนเส้น + ชื่อ + ลูกศรพับ, รายการที่เลือกเป็นแคปซูลพื้นสีหลักอ่อน ตัวสีหลัก, เมนูย่อยเป็นขีด “-” เยื้องเข้า
- **แถบบน** การ์ดขาวลอยสูง 56px: ปุ่ม ☰ ซ้าย; สลับมืด/สว่าง, ภาษา, กระดิ่ง, รูป+ชื่อผู้ใช้ ขวา
- **หัวหน้า** ชื่อหน้า 18px ซ้าย, breadcrumb ขวา (ระดับแรกสีหลัก, คั่นด้วย ›)
- **Dashboard** แถวการ์ดสถิติ 4 ใบ (วงกลมไอคอนสี + ตัวเลขใหญ่ + ป้าย), แถวการ์ดย่อย 6 ใบ (ไอคอนวงกลมกลาง ป้าย ตัวเลขสีหลัก), กราฟ 2 ใบ, ตารางนัด + รายชื่อแพทย์
- **ตาราง** อยู่ในกรอบมุมโค้ง หัวตารางพื้นสีหลักอ่อนมาก ตัวสีหลัก มีเส้นแนวตั้งแบ่งคอลัมน์ แถวสูง ~52px รูปวงกลม 28px หน้าชื่อ
- **ฟอร์ม** การ์ด “Basic Information” 2 คอลัมน์ ป้ายเหนือช่อง ปุ่ม Submit (สีหลัก) + Cancel (เทา) ชิดขวา
- **แชท** 2 แผง: Inbox (ค้นหา + การ์ดบทสนทนา, อันที่เลือกพื้นเทา) / ห้องแชท (ข้อความเราพื้นสีหลักอ่อนตัวสีหลัก ชิดขวา, อีกฝั่งพื้นเทา ชิดซ้าย, เวลาเล็กใต้รูป)

## 3. สิ่งที่ทำแล้วในรอบนี้

- ธีมระบบภายในทั้งชุดใน `admin.css` ครอบทุกหน้าที่ใช้ `doctor_base.html` โดยไม่ต้องแก้หน้าเดิม: การ์ด ตาราง ฟอร์ม ปุ่ม ป้าย แถบเลือก
- `doctor_base.html` ใหม่: เมนูข้างลอยแบบพับกลุ่มได้, แถบบนลอย, หัวหน้า + breadcrumb, โหมดมืด, เมนูมือถือใช้รายการเดียวกับจอใหญ่ (เดิมมือถือขาดเมนูไปครึ่งหนึ่ง)
- Dashboard แพทย์จัดใหม่ตามโครง Medicare
- หน้าเว็บสาธารณะ: header 2 ชั้น, hero, การ์ดลอย, หัวข้อสองน้ำหนัก, แผงบริการแบบตาราง, แถบเขียว, FAQ, แถบติดต่อ, footer ขาว, ปุ่มกลับขึ้นบน

- รอบที่ 2: จัด 3 หน้าตามโครง Medicare
  - รายชื่อคนไข้ (Patient List): การ์ดเดียว ช่องค้นหาและกรองมีไอคอนนำหน้า ตารางมีรูปวงกลมหน้าชื่อ สถานะเป็นจุดสี
  - แฟ้มคนไข้ (Patient Detail): การ์ดข้อมูลซ้าย (รูป + รายการหัวข้อ/ค่า), ประวัติโดยย่อ, สัญญาณชีพล่าสุด, ตารางประวัติการตรวจ, ฟอร์ม SOAP, การ์ด SOAP
  - แชท LINE (Chat): หน้ารายการใช้ชิปแท็บพร้อมตัวนับ หน้าอ่านแชทเป็น 3 แผง กล่องแชท / ห้องแชทแบบฟองข้อความ / สรุป SOAP (จอ < 1400px ซ่อนกล่องแชท จอ < 992px เรียงลงล่าง)
  - แผงกล่องแชทแสดงแค่ชื่อ สถานะ และเวลา ไม่แสดงเนื้อหาข้อความ เพราะกล่องอื่นอาจยังล็อกอยู่

## 4. ยังไม่ได้ทำ

- หน้าอื่นของระบบภายในยังใช้ HTML เดิม เพียงเปลี่ยนหน้าตาตามธีม (เช่น นัดหมาย, กล่องข้อความรวม, ตรวจทานเคส, ฟอร์มเพิ่ม/แก้ไขคนไข้)
- หน้า portal คนไข้ (`patient_base.html`, `portal/base_portal.html`) ยังไม่เปลี่ยน
- ยังไม่มีรูปถ่ายจริงของคลินิก hero ใช้ภาพใบไม้ 3 มิติเดิมแทนรูปคน
