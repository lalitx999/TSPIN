## 4. ภาษาดีไซน์ "TSPI 2026" (ร่าง)

- พื้น `#F7F7F5` การ์ดขาว ขอบ 1px บาง เงานุ่ม 3 ระดับ มุม 16 / 22 / 32px ปุ่มแคปซูล
- ปุ่มหลักสีหมึก, สีแบรนด์คลินิกใช้เป็นสีเน้น (ป้าย จุด แสงฟุ้ง คำสำคัญในหัวข้อ) ไม่ใช้เป็นพื้นใหญ่
- หัวข้อสองโทน ขนาด `clamp()` ตามจอ น้ำหนัก 500–600, line-height ไทยไม่ต่ำกว่า 1.3 (กันสระถูกตัด)
- กระจกเบลอเฉพาะแถบบน เมนูมือถือ ปุ่มลอย (ไม่ใช้ทั้งหน้า — เปลืองเครื่องมือถือรุ่นเก่า)
- ไอคอนล้วน ไม่ใช้อิโมจิ
- โหมดมืดตามเครื่องผู้ใช้ (`prefers-color-scheme`) ผ่าน `data-bs-theme`
- เคลื่อนไหวเบา ๆ (เผยตอนเลื่อน, hover ยกการ์ด) ปิดเมื่อผู้ใช้ตั้ง reduced motion

## 5. UX ที่จะปรับ (ไม่ใช่แค่หน้าตา)

- **หน้าแรกเล่าเรื่องเดียวชัด ๆ:** ปัญหาสุขภาพเรื้อรัง → แนวทาง 39 แกน → ขั้นตอนมาคลินิก → ช่องทางเริ่ม (คุย AI / ทัก LINE / นัดหมาย) → คำถามพบบ่อย → CTA ปิดท้าย
- **ทางไปต่อเดียวต่อหน้า:** ปุ่มหลัก 1 ปุ่ม ปุ่มรอง 1 ปุ่ม
- **ปุ่มคุยกับ AI ลอยทุกหน้า** ไป `/ai/` (หน้าบ้านเท่านั้น)
- **Portal คนไข้แบบแอปมือถือ:** เมนูล่าง 4–5 ปุ่ม (หน้าหลัก / ประวัติ / ผู้ช่วย AI / นัด / ตั้งค่า), หน้าหลักเป็นการ์ดโปรไฟล์ + แถวตัวเลขจริง (นัดถัดไป, ผลล่าสุด) + งานที่ต้องทำ
- **ฟอร์ม login/สมัคร:** สองคอลัมน์ (ฟอร์ม + ภาพ) บนจอใหญ่, ช่องใหญ่ กดง่ายบนมือถือ
- **ไม่มีข้อมูลปลอม:** ไม่ใส่ตัวเลขสถิติ รีวิว หรือรูปคนไข้ที่แต่งขึ้น ถ้ายังไม่มีข้อมูลจริงให้ใช้ข้อความอธิบายแทน
