## 🛠️ 2. รายละเอียดงาน (Job Description)
ขอบเขตการพัฒนาระบบหลังบ้านและปัญญาประดิษฐ์เพื่อการวิเคราะห์ทางคลินิกเชิงลึก ประกอบด้วย:

1.  **การพัฒนาระบบวิเคราะห์สรีรวิทยา 4 เลเยอร์ (4-Layer Systems Biology Analytics)**
    *   **Layer 1 (3 Keys):** พัฒนาระบบประเมินกุญแจชีวภาพ 3 ด้าน (Metabolic Energy, Biological Dynamics, Biointegrity)
    *   **Layer 2 (9 Steps):** ติดตั้งอัลกอริทึมวิเคราะห์ลำดับขั้นบันไดการฟื้นฟูชีวภาพเวอร์ชันล่าสุด (ตั้งแต่ Detoxification จนถึง Prakati)
    *   **Layer 3 (12 Domains):** พัฒนาระบบให้คะแนนระดับความเสียหายของระบบสรีรวิทยาทางคลินิก 12 โดเมนหลัก (สเกลคะแนน 0-10)
    *   **Layer 4 (39 Axes & 180 Networks):** ติดตั้งตรรกะการจัดกลุ่มแกนสรีรวิทยาหลัก/รอง/สนับสนุน และอัลกอริทึมคัดเลือกเครือข่ายชีวภาพที่เกี่ยวข้องจำนวน 15-25 เครือข่ายจากระบบโครงข่าย 180 เครือข่าย
2.  **การพัฒนา Pipeline การเจนรายงานแพทย์ 20 บท (20-Chapter Medical Report Generator)**
    *   พัฒนาเทมเพลตและคำสั่งป้อนข้อมูลปัญญาประดิษฐ์ (Prompt Engineering) ภาษาไทยทางการแพทย์เชิงลึกในรูปแบบเฉพาะของแพทย์ผู้เชี่ยวชาญ
    *   พัฒนาระบบแบ่งกลุ่มประมวลผลแบบคู่ขนาน (Parallel Batch Processing Engine) ด้วย Genkit + Gemini API เพื่อให้ประมวลผลรายงานขนาดใหญ่ (ความยาวประมาณ 20-30 หน้ากระดาษ) ได้สำเร็จโดยไม่มีปัญหาระบบหลุดจากการหมดเวลาเชื่อมต่อ (Network Timeout)
3.  **การพัฒนาระบบค้นหาความรู้เวกเตอร์ความเร็วสูง (Vector DB / RAG Optimization)**
    *   ปรับปรุงระบบจัดเก็บข้อมูลเชิงความหมายใน Firestore Vector DB
    *   ทำดัชนีและเชื่อมโยงระบบค้นหา RAG คลังตำรับยาสมุนไพรและสารพฤกษเคมีบำบัด (Phytochemical Modules) กว่า 816 รายการ
    *   เชื่อมต่อฐานข้อมูล Few-Shot Examples (Q&A) ของเคสที่แพทย์เคยตรวจ เพื่อให้ AI นำรูปแบบการวิเคราะห์ที่ถูกต้องไปใช้อ้างอิง
4.  **การเชื่อมต่อและทดสอบระบบหลังบ้าน (Backend Integration & API Deployment)**
    *   พัฒนา API Endpoint บน Firebase Cloud Functions ให้ฝั่งเว็บพอร์ทัลแพทย์ (Doctor Portal Dashboard) เรียกใช้งานเพื่อสร้างรายงานได้ทันที
    *   พัฒนาระบบรับส่งพารามิเตอร์ข้อมูลแล็บและประวัติคนไข้ทางโครงสร้าง JSON ที่ปลอดภัย

## 📦 3. สิ่งที่ลูกค้าจะได้รับ (Deliverables)
1.  **ระบบหลังบ้าน API (Deployable Cloud Services):** API Endpoint บน Google Cloud/Firebase Functions ที่พร้อมรันระบบประมวลผลรายงาน 20 บทเต็มรูปแบบ
2.  **ฐานข้อมูลเวกเตอร์บนคลาวด์ (Firestore Vector Database):** คลังข้อมูล RAG ที่มีการทำดัชนีเวกเตอร์อย่างสมบูรณ์ในคอลเลกชัน `tspi_axes_v4`, `tspi_modules_vectors`, และ `tspi_qa_vectors`
3.  **เอกสารคู่มือทางเทคนิค (Technical Documentation):** คู่มือแสดงโครงสร้างข้อมูล API Schema และวิธีการนำระบบขึ้นติดตั้ง (Deployment Guide)
4.  **รายงานการทดสอบความแม่นยำระบบ (Validation & Test Report):** ตัวอย่างผลลัพธ์รายงานวิเคราะห์โรคเชิงลึกของคุณสีมาพรและกรณีทดสอบจำลอง (Test Cases) ความยาว 20 บท ขนาด ~196.6 KB

## 🔄 4. ขอบเขตการแก้ไขงาน (Project Revisions)
*   **การทดสอบระบบและแก้ไขข้อผิดพลาด (UAT & Bug Fixes):** ดูแลแก้ไขจุดผิดพลาดทางเทคนิคและสคริปต์หลังบ้านที่ไม่ตรงตามข้อตกลงอย่างไม่จำกัดจำนวนครั้ง เป็นเวลา 14 วันทำการหลังจากส่งมอบระบบรอบทดสอบ
*   **การปรับแต่งสำนวนรายงานและเงื่อนไข Prompt:** สามารถขอปรับแต่งแนวทางคำตอบของ AI, รูปแบบตารางสรุป, และสำนวนภาษาแพทย์ไทยในรายงานได้ไม่เกิน **3 รอบใหญ่** (โดยโครงสร้างยังอยู่ภายใต้หัวข้อย่อยและกรอบ 20 บทเรียนรู้ที่ตกลงกันไว้)
*   **ขอบเขตนอกเหนือสัญญา (Out of Scope):** หากทางผู้ว่าจ้างต้องการปรับเพิ่มโครงสร้างบทรายงานเพิ่มเติมนอกเหนือจาก 20 บทข้างต้น หรือเพิ่มฟีเจอร์การดึงภาพรังสี/ผลการตรวจแล็บชนิดใหม่จากเครื่องตรวจโดยตรง จะถือเป็นฟีเจอร์เพิ่มเติมและคิดค่าบริการตามประเมินร่วมกันภายหลัง

1.  **ระยะเวลาดำเนินการ (Timeline):** 
    *   คาดการณ์ระยะเวลาประมวลผลและส่งมอบงานเสร็จสมบูรณ์ภายใน **45 - 50 วันทำการ** (ไม่รวมวันหยุดเสาร์-อาทิตย์และวันหยุดนักขัตฤกษ์) โดยเริ่มนับจากวันที่ผู้รับจ้างได้รับชำระเงินมัดจำงวดที่ 1 และได้รับข้อมูลนำเข้าครบถ้วน
2.  **เงื่อนไขการชำระเงิน (Payment Milestones):** แบ่งการชำระเงินออกเป็น 3 งวด ดังนี้:
    *   **งวดที่ 1 (มัดจำเริ่มงาน):** ชำระ **40%** ของราคารวม เมื่อลงนามอนุมัติใบเสนอราคาและสัญญาเริ่มโครงการ
    *   **งวดที่ 2 (ส่งงานรอบทดสอบ):** ชำระ **40%** ของราคารวม เมื่อส่งมอบสคริปต์ประมวลผลขนาน API บน Staging Environment และแสดงผลลัพธ์รายงานที่สร้างสำเร็จ
    *   **งวดที่ 3 (ส่งมอบงานสมบูรณ์):** ชำระ **20%** ของราคารวม เมื่อเชื่อมต่อ API ร่วมกับระบบเว็บหน้าบ้านของคลินิกเสร็จสิ้น ทดสอบฟังก์ชันงานขึ้น Production และส่งมอบเอกสารและรหัสผ่านทั้งหมด
3.  **ค่าบริการภายนอก (Third-Party & Infrastructure Fees):**
    *   ค่าใช้จ่ายเกี่ยวกับทรัพยากรระบบ เช่น Google Cloud Services, Firebase Usage, Gemini API Keys, Domain, และ SSL Certificate จะได้รับการชำระโดยตรงจากบัญชีบัตรเครดิตหรือบัญชีคลาวด์ของผู้ว่าจ้างเอง (ผู้พัฒนาทำหน้าที่เตรียมความพร้อมระบบและติดตั้งสิทธิ์ความปลอดภัยให้)
4.  **กรรมสิทธิ์ในผลงาน (Intellectual Property):**
    *   ซอร์สโค้ดการประมวลผล 4 เลเยอร์ คู่มือ พร้อมทั้งโครงสร้างข้อมูลบน Firestore ทั้งหมด จะโอนย้ายสิทธิ์การเป็นเจ้าของให้แก่ผู้ว่าจ้างโดยสมบูรณ์ทันทีที่ผู้รับจ้างได้รับเงินชำระครบถ้วน 100% ตามข้อตกลงในใบเสนอราคานี้
