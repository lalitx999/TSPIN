# สรุปโมดูลจัดทำรายงานผู้ป่วยเชิงลึก (Deep Clinical Report Generator Module)

โมดูลนี้ได้รับการพัฒนาตามข้อกำหนดของโครงร่างโครงการ **TSPI (Thai Systems Pharmacology Intelligence) เฟส 3** เพื่อให้ระบบสามารถจัดทำเล่มรายงานชีววิทยาระบบคลินิกเชิงลึกแบบอัตโนมัติจากเวชระเบียนเดิมและการป้อนข้อมูลเพิ่มเติมของคุณหมอหน้างาน พร้อมระบบประวัติย้อนหลังและพิมพ์ผลเป็น PDF ที่จัดเลย์เอาต์ A4 พรีเมียม

---

## 🧭 1. ข้อมูลทั่วไปของส่วนงาน (Component Summary)

- **หน้าอินเตอร์เฟสหลัก:** [page.tsx](file:///d:/Pr/dr_pat/frontend/src/app/doctor/ai-physician/page.tsx)
- **ฟังก์ชันการเชื่อมต่อ Firebase Cloud Function:** `generateDeepReportGenkit` (เรียกใช้ผ่านระบบ HTTPS Callable)
- **รูปแบบรายงานที่รองรับ:**
  1. **ฉบับแพทย์ (Physician Edition):** วิเคราะห์ 10 บทหลัก + 5 ภาคผนวก ใช้ศัพท์เทคนิคระดับวิชาชีพและการแพทย์เฉพาะทาง
  2. **ฉบับคนไข้ (Patient Edition):** สรุป 10 บทด้วยภาษาที่เป็นมิตร เข้าใจง่าย พร้อมเปรียบเทียบแนวทางปรับปรุงไลฟ์สไตล์
  3. **มัลติโอมิกส์ (Multi-Omics Edition):** จัดทำ 15 บทประเมินระดับ Confidences ของข้อมูลการแพทย์ NGS/Microbiome/Cytokines
- **การจัดเก็บประวัติ (History Caching):** ประมวลผลและเก็บข้อมูลลงใน Firestore คอลเลกชัน `tspi_generated_reports`

## 🛠️ 2. ตรรกะการประมวลผลและการป้อนข้อมูล (Data Intake & Logic Flow)

1. **Auto-Populate (การดึงข้อมูลอัตโนมัติ):**
   - เมื่อกดเปิดคอนโซล ระบบจะดึงข้อมูลอาการสำคัญ (`symptoms`) และประวัติการรักษา (`history`) จากข้อมูลเวชระเบียนของแพทย์หรือบันทึก EMR ของคนไข้รายนั้นๆ มาใส่ไว้ให้
   - สแกนหาตัวชี้วัดสำคัญของตารางแล็บปัจจุบัน เช่น ค่าน้ำตาลตอนเช้า (`FBS`), ค่าน้ำตาลสะสม (`HbA1c`), และผลสแกนหลอดเลือด (`Doppler`) จากนั้นจัดหมวดแยกส่งไปยังอินพุตพารามิเตอร์ของฟังก์ชัน
   - เปรียบเทียบตัวแปรแล็บอื่นๆ (เช่น Lipid profile, Liver enzymes) ในรูปแบบของพจนานุกรมคีย์-เวกเตอร์ เพื่อวิเคราะห์แกนชีวภาพเชิงโครงสร้าง
2. **Progress Status Visualization (แถบสถานะ):**
   - แสดงสเตตัสกระบวนการคิดของโมเดล RAG ตามประเภทรายงานที่เลือก เช่น สแกนแกนชีวภาพ 39 แกน, สังเคราะห์ลำดับ восстановления (Restore Ladder), และเขียนข้อสรุปทางคลินิก
   - **ข้อจำกัดเรื่องสี (Flat Theme Constraint):** ใช้สีเดี่ยวระนาบเดียวกันเท่านั้น ได้แก่ สีน้ำเงินแบรนด์แพทย์ (`#0A5C8E`) และสีเขียวระบบ (`#059669`) ปราศจากการไล่เฉดสีผสม (No Gradients)

## 🖨️ 3. ข้อกำหนดการพิมพ์จัดหน้าเอกสาร A4 (CSS Print Layout Specs)

การพิมพ์หน้าเล่มรายงาน PDF ใช้เทคนิค **Client-Side CSS Print Styles (`window.print()`)** โดยมีพฤติกรรมโครงสร้างดังนี้:

- **หน้าปกพรีเมียม (Cover Page):** แสดงหัวข้อเอกสาร *TSPI Precision Biological Network Intelligence Report™*, แสดงโลโก้, ชื่อ-นามสกุลของคนไข้, เลข HN, วันที่และเวลาที่จัดทำเล่มรายงาน และชื่อแพทย์ผู้ประเมินผล
- **สารบัญแบบไดนามิก (Table of Contents):** แสดงลำดับรายการของแต่ละบทความพร้อมเลขหน้าเริ่มต้นโดยอัตโนมัติ
- **การเว้นบรรทัดและการจัดระเบียบหน้ากระดาษ:**
  - `page-break-before: always;` / `break-before: page;` บังคับให้แต่ละบทหลักเริ่มขึ้นหน้ากระดาษแผ่นใหม่เสมอเพื่อความเรียบร้อย
  - `page-break-inside: avoid;` / `break-inside: avoid;` ป้องกันไม่ให้ตารางหรือหัวข้อย่อยที่มีความยาวถูกหั่นแหว่งขาดครึ่งไปคนละหน้ากระดาษ
- **ซ่อนหน้าต่างหลัก:** ซ่อนแถบควบคุม เมนูนำทาง และอินเตอร์เฟสเบื้องหลังทั้งหมดในขณะพิมพ์ ให้เหลือแต่กระดาษรายงานสีขาวล้วนและฟอนต์ `Sarabun` / `Inter` สำหรับพิมพ์

## 💾 4. ข้อมูลโครงสร้างแบบ EMR API (Data Structures)

ฟังก์ชันเชื่อมต่อใช้รูปแบบ EMR API บริการ Firestore ดังนี้:

- **`saveGeneratedReport(patientId, name, hn, reportType, inputsUsed, reportData)`**
  - จัดเก็บข้อมูลเล่มรายงานฉบับล่าสุดลงบนคอลเลกชัน `tspi_generated_reports` เพื่อป้องกันการสูญหายและการเรียกเจนซ้ำ
- **`getGeneratedReports(patientId)`**
  - ดึงข้อมูลเล่มรายงานเก่าทั้งหมดของคนไข้มาแสดงผลในแถบประวัติด้านขวาของคุณหมอ
- **`deleteGeneratedReport(reportId)`**
  - ลบประวัติเล่มที่ต้องการออกจากการบันทึกของคนไข้
