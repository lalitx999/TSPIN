## ⚡ 2. การกู้คืนระบบและชัยชนะทางวิศวกรรม (Technical Victories & Bug Fixes)

### 📌 แก้ปัญหา Next.js Turbopack ค้าง (Compiler Hang Fix)
* **สาเหตุ:** การนำตัวแปร JavaScript (เช่น `${primaryColor}`) ไปใส่และแทนที่ข้อความข้างในแท็ก `<style jsx>` บน Next.js 16 ส่งผลให้ตัวแปล Turbopack เกิดอาการค้างและค้างตลอดการพัฒนา
* **การแก้ไข:** แก้ไขไฟล์สไลด์เมนูของทั้งระบบ [Sidebar.tsx](file:///Users/tanchonl/Downloads/drpatt/frontend/src/components/dashboard/Sidebar.tsx) โดยเปลี่ยนมาใช้ระบบ CSS Variables ในตัวแบรนดิ้งหลัก ทำให้หน้าลงทะเบียนและหน้าล็อกอินผ่านได้โดยไม่มีอาการค้างอีกเลย

### 📌 แก้ปัญหา Module Not Found ของ `google-auth-library` บนเว็บเบราว์เซอร์
* **สาเหตุ:** ตัวคอมไพเลอร์ของ Next.js พยายามแพ็กรหัสการตรวจสอบสิทธิ์ของฝั่งเซิร์ฟเวอร์ (Node.js) ขึ้นไปอยู่บนเว็บเบราว์เซอร์ของคนไข้ ทำให้ระบบเรียกหาโมดูล `fs`, `net`, `tls` ของระบบปฏิบัติการซึ่งไม่มีอยู่จริงในเบราว์เซอร์
* **การแก้ไข:** เปลี่ยนมาเรียกใช้งาน `google-auth-library` ด้วยเทคนิค `eval("require")` และทำงานเฉพาะฝั่งเซิร์ฟเวอร์ผ่านเช็คเงื่อนไข `typeof window === "undefined"` ใน [functions-client.ts](file:///Users/tanchonl/Downloads/drpatt/frontend/src/utils/firebase/functions-client.ts) ส่งผลให้สามารถ Build หน้าบ้านผ่านสำเร็จ 100%

### 📌 แก้ไขโครงสร้างไฟล์ JSX หน้าสแกนแล็บ (JSX Nesting Fix)
* **สาเหตุ:** การปิดปีกกาและปิดแท็ก `</div>` ผิดพิกัดบริเวณล่างสุดของไฟล์ [lab-ocr/page.tsx](file:///Users/tanchonl/Downloads/drpatt/frontend/src/app/doctor/lab-ocr/page.tsx)
* **การแก้ไข:** ขยับบล็อกสไตล์ `<style jsx>` ให้อยู่ภายใต้กรอบของ Wrapper Div หลัก ทำให้ตัวคอมไพเลอร์ Turbopack แกะวิเคราะห์ซอร์สโค้ดได้อย่างสมบูรณ์
