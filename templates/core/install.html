Progressive Web App (PWA)

ติดตั้งแอป TSPI CLINIC บนสมาร์ตโฟน

ใช้งานได้สะดวกเหมือนแอปพลิเคชันทั่วไป เปิดได้จากหน้าจอโฮม รับการแจ้งเตือนผลตรวจ และไม่ต้องเปลืองพื้นที่ดาวน์โหลด

1
เปิดเว็บไซต์ด้วย Safari

เข้าสู่เว็บไซต์ tspiclinic.com ด้วยเบราว์เซอร์ Safari บน iPhone หรือ iPad ของท่าน

2
กดปุ่มแชร์ (Share Icon)

กดที่ปุ่มแชร์รูปสี่เหลี่ยมที่มีลูกศรชี้ขึ้น ที่แถบด้านล่างของหน้าจอ Safari

3
เลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)

เลื่อนลงมาในเมนูแชร์ และกดเลือก "เพิ่มไปยังหน้าจอโฮม" แล้วกดปุ่ม "เพิ่ม" (Add)

1
เปิดเว็บไซต์ด้วย Google Chrome

เข้าสู่เว็บไซต์ tspiclinic.com ด้วยเบราว์เซอร์ Chrome บนสมาร์ตโฟน Android ของท่าน

2
กดปุ่มเมนู 3 จุด

กดที่จุด 3 จุดมุมบนขวาของเบราว์เซอร์ Chrome

3
เลือก "ติดตั้งแอป" (Install App)

กดเลือก "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก" แล้วกดยืนยันการติดตั้ง
