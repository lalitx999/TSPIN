{% translate "TSPI Clinic ให้ความสำคัญสูงสุดต่อการรักษาความปลอดภัยของข้อมูลส่วนบุคคล (Personal Data) และข้อมูลสุขภาพที่มีความอ่อนไหวสูง (Sensitive Health Data) ของผู้รับบริการทุกท่าน ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562" %}

{% translate "1. ข้อมูลที่เราจัดเก็บและประมวลผล" %}

  • {% translate "ข้อมูลระบุตัวตน: ชื่อ, นามสกุล, หมายเลขประจำตัวประชาชน (จัดเก็บในรูปแบบการเข้ารหัสปลอดภัย)" %}
  • {% translate "ข้อมูลติดต่อ: เบอร์โทรศัพท์มือถือ, อีเมล" %}
  • {% translate "ข้อมูลสุขภาพ: ผลการตรวจวิเคราะห์ทางห้องปฏิบัติการ (Labs), อาการสำคัญ (Symptoms), คะแนนทางชีววิทยา 39 แกน (12 โดเมน)" %}

{% translate "2. วัตถุประสงค์ในการนำข้อมูลไปใช้" %}

{% translate "เราใช้ข้อมูลสุขภาพเพื่อวัตถุประสงค์ในการตรวจวินิจฉัย การวางแผนบำบัดรักษาฟื้นฟูโดยแพทย์ผู้รักษา และการประมวลผลคะแนนชีวภาพผ่านระบบ AI ปัญญาประดิษฐ์ทางการแพทย์ที่ผ่านการรับรอง โดยไม่มีการนำข้อมูลไปจำหน่ายหรือส่งต่อให้บุคคลภายนอกโดยไม่ได้รับความยินยอมเป็นลายลักษณ์อักษร" %}

{% translate "3. มาตรการรักษาความปลอดภัยข้อมูล" %}

{% translate "ระบบทำงานภายใต้สถาปัตยกรรมความปลอดภัยระดับสูง การแฮชรหัสผ่านด้วย Argon2, การควบคุมสิทธิ์แบบเข้มงวด (Role-Based Access Control), การจัดเก็บประวัติการเข้าถึงข้อมูล (Audit Logging), และการหมดอายุเซสชันอัตโนมัติ (Idle Session Timeout)" %}
